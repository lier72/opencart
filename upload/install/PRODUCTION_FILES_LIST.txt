INSTALLATION CHECKLIST FOR PRODUCTION
===================================================================

[0] Check MySQL Version:
    □ Run: SELECT VERSION();
    □ If version is 5.6.x, use *_mysql56.sql files
    □ If version is 5.7+ or 8.x, use regular .sql files

[1] Database Setup FOR MYSQL 5.6:
    □ Run order_triggers_simplified_oc3_mysql56.sql on OC3 database
    □ Run order_triggers_simplified_oc2_mysql56.sql on OC2 database
    □ Run order_history_triggers_oc3_mysql56.sql on OC3 database
    □ Run order_history_triggers_oc2_mysql56.sql on OC2 database
    □ Run customer_activity_triggers_oc3_mysql56.sql on OC3 database
    □ Run customer_activity_triggers_oc2_mysql56.sql on OC2 database
    □ Run odoo_order_map_triggers_oc3_mysql56.sql on OC3 database
    □ Run odoo_order_map_triggers_oc2_mysql56.sql on OC2 database
    □ Run order_to_sdek_triggers_oc3_mysql56.sql on OC3 database
    □ Run order_to_sdek_triggers_oc2_mysql56.sql on OC2 database
    □ Run drop_related_table_triggers.sql to remove old triggers
    □ Verify ocus_order_sync_queue table exists in both databases

[1] Database Setup FOR MYSQL 5.7+:
    □ Run order_triggers_simplified_oc3.sql on OC3 database
    □ Run order_triggers_simplified_oc2.sql on OC2 database
    □ Run order_history_triggers_oc3.sql on OC3 database
    □ Run order_history_triggers_oc2.sql on OC2 database
    □ Run customer_activity_triggers_oc3.sql on OC3 database
    □ Run customer_activity_triggers_oc2.sql on OC2 database
    □ Run odoo_order_map_triggers_oc3.sql on OC3 database
    □ Run odoo_order_map_triggers_oc2.sql on OC2 database
    □ Run order_to_sdek_triggers_oc3.sql on OC3 database
    □ Run order_to_sdek_triggers_oc2.sql on OC2 database
    □ Run drop_related_table_triggers.sql to remove old triggers
    □ Verify ocus_order_sync_queue table exists in both databases

[2] Worker Setup:
    □ Upload order_sync_worker.php to cli/ directory
    □ Copy order_sync_config.php.template to order_sync_config.php
    □ Edit order_sync_config.php with your database credentials:
      - OC3_DB_HOST, OC3_DB_USER, OC3_DB_PASS, OC3_DB_NAME
      - OC2_DB_HOST, OC2_DB_USER, OC2_DB_PASS, OC2_DB_NAME
      - Each database can have DIFFERENT credentials
    □ Set correct permissions: chmod +x cli/order_sync_worker.php
    □ Test worker: php cli/order_sync_worker.php

[3] Cron Job (optional but recommended):
    □ Add to crontab: */5 * * * * php /path/to/cli/order_sync_worker.php

[4] Verification:
    □ Create test order in OC2
    □ Check queue: Should have ~26 entries (not 773!)
    □ Run worker manually
    □ Verify order synced to OC3 with all products/totals
    □ Check reverse sync: Should be 0 entries in OC3 queue
