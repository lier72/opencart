# RUS-размеры обуви (Uniqsport)

Единая шкала RUS по длине стопы для всех брендов и сеток (Li-Ning унисекс / женская / детская / baby, Victor).
Хранение в OpenCart не меняется: опции 22, 23, 26, 29 со значениями вида `41 us(8)` и `130mm us(7C)`.
RUS вычисляется из этих значений: US → длина стопы (мм) → RUS.

## Что меняется

| Где | Что видит покупатель / менеджер |
|---|---|
| Карточка товара (Size Selector) | RUS по умолчанию и длина стопы под каждым размером; переключатель RUS / EU / US / UK / мм. Для Victor EU/UK/US берутся с коробки Victor |
| «Таблица размеров» | Таблица по сетке товара (Li-Ning или Victor) со столбцом RUS |
| Фильтр в каталоге | Группа фильтров **«Размер (RUS)»**: только RUS, только размеры в наличии |
| Заказ (письмо, ЛК, админка) | `41 us(8) · RUS 40` — исходное значение для склада + RUS, который выбрал покупатель |

## Шкала

210–315 мм совпадает со Спортмастером. Ниже — их же формула `RUS = 1,5 × см + 1,5` (0,25/0,75 → до целого), выше 315 мм — +0,5 на 5 мм.
Полная шкала и сетки — в `system/library/sizerus.php`.

## Установка

1. Выложить файлы ветки (git → сборка образа → `docker compose up`, как обычно).
2. Выполнить SQL (события + RUS по умолчанию):
   ```bash
   mysql -u USER -p a1627-unqs-oc3 < install/size_rus_install.sql
   ```
3. Проверить, что все значения опций распознаются:
   ```bash
   php cli/sync_size_filter.php --check
   ```
   Строки с `!!` — значения без `us(...)` / `...mm` или вне сетки. Исправить их в «Каталог → Опции».
4. Создать и заполнить фильтр:
   ```bash
   php cli/sync_size_filter.php
   ```
5. Journal 3 → Модули → Filter: добавить пункт «Filters» для группы «Размер (RUS)» и убрать из фильтра опции
   22 / 23 / 26 / 29. Если в модуле включена проверка по категориям (filtersCategoryCheck) — скрипт сам привязывает
   фильтры к категориям товаров.
6. Сбросить кэш Journal 3 и проверить карточку Li-Ning, Victor, женской и детской модели.

## Когда пересобирается фильтр

- автоматически — при сохранении товара в админке и при смене статуса заказа (остатки);
- вручную или по cron — `php cli/sync_size_filter.php` (нужно, если остатки меняются в обход OpenCart:
  импорт, синхронизация с учётной системой). Пример для контейнера на NAS, раз в 15 минут:
  ```
  */15 * * * * docker exec <контейнер> php <путь к сайту>/cli/sync_size_filter.php >/dev/null 2>&1
  ```

## Настройка

`system/library/sizerus.php`:
- `$options` — номера опций и привязка US → мм (если поменяются option_id);
- `FILTER_GROUP_NAME` — название группы фильтров;
- `$rusByMm` — шкала RUS;
- `$victor` — сетка Victor с коробки.

Бренд определяется по производителю: в названии `victor` → сетка Victor, иначе Li-Ning.

## Откат

```sql
DELETE FROM ocus_event WHERE code LIKE 'size_rus_%';
UPDATE ocus_j3_size_selector_settings SET setting_value = 'EU' WHERE setting_key = 'default_size_system';
```
Группу «Размер (RUS)» можно удалить в «Каталог → Фильтры».
