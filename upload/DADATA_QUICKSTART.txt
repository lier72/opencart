================================================================================
  SETUP IN 3 EASY STEPS
================================================================================

STEP 1: GET YOUR API KEY

  1. Visit: https://dadata.ru
  2. Register/Login
  3. Get your API token (FREE: 10,000 requests/day)

STEP 2: CONFIGURE THE API KEY

  1. Open: catalog/view/theme/journal3/js/dadata-autocomplete.js
  2. Find line 15:
     apiKey: 'YOUR_DADATA_API_KEY_HERE',
  3. Replace with your key:
     apiKey: 'your_actual_api_key_here',
  4. Save the file

STEP 3: CLEAR CACHE

  Option A (Admin Panel):
    • Go to Dashboard → Developer Settings
    • Click "Clear" for Theme cache and SASS cache

  Option B (Manual):
    • Delete: /Users/max/Sites/storage/cache/*

================================================================================
  TROUBLESHOOTING
================================================================================

NOT WORKING?

  1. Open browser console (F12)
  2. Look for: "DaData Autocomplete: Initializing..."
  3. Check for errors or warnings
  4. Verify API key is correct (no quotes removed)
  5. Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)

STILL NOT WORKING?

  • Check: DADATA_SETUP.md for detailed troubleshooting
  • Verify: JavaScript file is loading (view page source)
  • Confirm: Internet connection is working
  • Test: Visit https://dadata.ru/api/ to check API status

================================================================================
  CUSTOMIZATION
================================================================================

CHANGE MINIMUM TYPING CHARACTERS:
  • Edit line 89 in dadata-autocomplete.js
  • Change: if (query.length >= 3) to another number

CHANGE TYPING DELAY:
  • Edit line 68 in dadata-autocomplete.js
  • Change: var doneTypingInterval = 300; to higher value

CHANGE NUMBER OF SUGGESTIONS:
  • Edit line 240 in dadata-autocomplete.js
  • Change: count: 10 to desired number
